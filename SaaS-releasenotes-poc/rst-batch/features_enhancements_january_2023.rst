New Features and Enhancements (January, 2023)
=============================================

This release includes the following new features and enhancements:

- **Arcserve Identity for Authentication:** Arcserve Cloud Direct has
  changed its current built-in authentication system to Arcserve
  Identity. This system uses multiple authentication systems with
  different multi-factor methods such as OKTA Verify, Biometric
  Authenticator, Google Authenticator, and SMS Authenticator.
  Additionally, Arcserve Identity allows connection of Cloud Direct with
  other Arcserve products, thereby providing Single-Sign-On (SSO).
- **MSP Sub-organization:** The MSP sub-organization admins previously
  owned user management. From this release, an exclusive MSP user
  management profile will manage the sub-organizations.
- **Terminologies:** The following UI terms have been changed in the
  Arcserve Console - SaaS UI.

  ======================= ======================
  Previously used UI Term Currently used UI Term
  Monitor                 Dashboard
  Analyze                 Reports
  Configure               Settings
  ======================= ======================

- **Dashboard**
- The following items have been moved to the Reports page:

  - Top 10 Sources
  - Backup Jobs Summary
  - Cloud Direct Data Transfer Summary
  - Usage Trend for Cloud Direct Volumes

- The following items have been removed from the console:

  - Top 10 Sources - Event
  - Top 10 Sources - Duration
  - Top 10 Sources - Data Transferred

- **Trial Management:** The Trial management option is now available in
  the Dashboard section.
- **UI Changes**
- The following UI pages have been changed:

  - Login page
  - Changes to color and layout in the Dashboard page
  - User Accounts page in the Settings section
