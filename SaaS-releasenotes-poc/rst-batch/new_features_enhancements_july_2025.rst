New Features and Enhancements (July, 2025)
==========================================

This release primarily provides the following:

New Features
------------

- **Arcserve Cyber Resilient Storage Account Support:** Allows you to
  back up and replicate data to Arcserve-supported cyber resilient
  storage. For more information, see `Add an Arcserve Cyber Resilient
  Storage
  Account <https://documentation.arcserve.com/Arcserve-Console/SaaS/Available/ENU/olh/default.htm#Arcserve%20Console%20-%20SaaS/add_crs_account.htm?TocPath=Understanding%2520Arcserve%2520UDP%257CProtect%257CDestinations%257CAdd%2520a%2520Destination%257CAdd%2520an%2520Arcserve%2520Cyber%2520Resilient%2520Storage%25C2%25A0Account%257C_____0>`__.

  - **Arcserve Cyber Resilient Data Store:** Allows you to take
    immutable snapshots of an entire data store to an on-premises
    storage endpoint for enhanced protection against ransomware and
    other threats. For more information, see `Add an Arcserve Cyber
    Resilient Data
    Store <https://documentation.arcserve.com/Arcserve-Console/SaaS/Available/ENU/olh/default.htm#Arcserve%20Console%20-%20SaaS/add_crs_data_store.htm?TocPath=Understanding%2520Arcserve%2520UDP%257CProtect%257CDestinations%257CView%2520and%2520Manage%2520Destinations%257CView%2520and%2520Manage%2520Recovery%2520Point%2520Servers%257C_____5>`__.
  - **Note:** The Arcserve Cyber Resilient Storage feature requires a
    minimum Recovery Point Server (RPS) version of 10.2.

- **Request Trial:** Allows you to request a trial for the following
  features using the `Try
  It <https://documentation.arcserve.com/Arcserve-Console/SaaS/Available/ENU/olh/default.htm#Arcserve%20Console%20-%20SaaS/Request%20Trial%20.htm?TocPath=Understanding%2520Arcserve%2520Console%2520-%2520SaaS%257C_____11>`__
  option.

  - Add Arcserve Cyber Resilient Data Store
  - Add Arcserve Cloud Data Store
  - Add Arcserve Cloud Cyber Resilient Data Store
