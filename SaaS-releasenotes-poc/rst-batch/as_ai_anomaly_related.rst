Assured Security - AI Anomaly Detection Related
===============================================

- Assured Security – AI Anomaly Detection does not support Oracle
  sources. However, for Oracle sources running on Windows, the *Anomaly
  Detection* column incorrectly shows the status as *Scan Not Initiated*
  when viewing anomaly detection results and during recovery operations.
- The Assured Security - AI Anomaly Detection feature does not support
  the following:

  - REFS file system
  - Linux sources
  - On-demand or Ad-hoc jobs
  - Oracle RMAN source type
  - Application-aware protection
