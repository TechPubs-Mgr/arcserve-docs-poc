Nutanix Related
===============

- Arcserve Console - SaaS does not support the backup of Nutanix Files
  UNC Share with a long directory path containing multiple levels of
  folders.
- Currently, Arcserve supports the following:

  - **Length of path:** A maximum of 240 characters is allowed.
  - **Depth of path:** A maximum of 80 nested folders is allowed.

- Discover virtual machines is not supported on Nutanix Prism Central.
- Assured Recovery has the following limitations:

  - The Instant Virtual Machine (IVM) option is supported only for the
    Linux virtual machines.
  - The Instant Virtual Disk (IVD) option is supported only for the
    Windows virtual machines.
