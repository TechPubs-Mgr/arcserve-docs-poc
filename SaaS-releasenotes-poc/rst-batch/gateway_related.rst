Gateway Related
===============

- The hostname containing underscore (\_) does not support gateway.
- Directly connect the local UDP Gateway using a router or firewall to
  Arcserve Console - SaaS, but not through a web proxy. The UDP Gateway
  setup wizard continues to show a screen for the HTTP proxy connection
  settings; however, these settings do not work with Arcserve Console -
  SaaS.
- **Note:** If your environment supports a SOCKS proxy, which you may
  want to use over a standard routing firewall, please contact Arcserve
  Support to register for an enhancement request. Arcserve is
  considering this enhancement for an upcoming UDP release.
