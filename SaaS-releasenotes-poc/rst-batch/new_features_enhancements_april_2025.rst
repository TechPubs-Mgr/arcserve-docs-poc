New Features and Enhancements (April, 2025)
===========================================

This release primarily provides the following:

New Features
------------

- **Copy Recovery Points:** Allows you to copy your backup data(recovery
  Points) from a source data store to a destination data store. For more
  information, see `Copy Recovery
  Points <https://documentation.arcserve.com/Arcserve-Console/SaaS/Available/ENU/olh/default.htm#Arcserve%20Console%20-%20SaaS/copy_recovery_points.htm?TocPath=Understanding%2520Arcserve%2520UDP%257CProtect%257CDestinations%257CView%2520and%2520Manage%2520Destinations%257CView%2520and%2520Manage%2520Recovery%2520Point%2520Servers%257C_____15>`__.
- **Nutanix Files Support:** Arcserve Console - SaaS now provides a way
  of protecting Nutanix Files using the UNC/NFS option. Nutanix Files is
  a software-defined, scale-out file storage solution that provides a
  repository for unstructured data, such as home directories, user
  profiles, departmental shares, application logs, backups, and
  archives. For more information, see `Add a UNC or NFS
  Path <https://documentation.arcserve.com/Arcserve-Console/SaaS/Available/ENU/olh/default.htm#Arcserve%20Console%20-%20SaaS/dc_add_unc_nfs_path.htm?TocPath=Understanding%2520Arcserve%2520UDP%257CProtect%257CSources%257CAdd%2520a%2520Source%2520%257CAdd%2520a%2520UNC%2520or%2520NFS%2520Path%257C_____0>`__.
- **Support for Arcserve Cloud Storage:** Allows you to back up and
  replicate data to Arcserve-supported cloud storage. For more
  information, see `Add a Cloud Account for Arcserve Cloud
  Storage <https://documentation.arcserve.com/Arcserve-Console/SaaS/Available/ENU/olh/default.htm#Arcserve%20Console%20-%20SaaS/add_cloud_act_cloud_storage.htm?TocPath=Understanding%2520Arcserve%2520UDP%257CProtect%257CDestinations%257CAdd%2520a%2520Destination%257CAdd%2520a%2520Cloud%2520Account%257CAdd%2520a%2520Cloud%2520Account%2520for%2520Arcserve%2520Cloud%2520Storage%257C_____0>`__.
- **Arcserve Cloud Cyber Resilient Data Store:** Allows you to take
  immutable snapshots of an entire data store for enhanced protection
  against ransomware and other threats. For more information, see `Add
  Arcserve Cloud Cyber Resilient Data
  Store <https://documentation.arcserve.com/Arcserve-Console/SaaS/Available/ENU/olh/default.htm#Arcserve%20Console%20-%20SaaS/add_arcserve_cloud_cyber_resilient_datastore.htm?TocPath=Understanding%2520Arcserve%2520UDP%257CProtect%257CDestinations%257CView%2520and%2520Manage%2520Destinations%257CView%2520and%2520Manage%2520Recovery%2520Point%2520Servers%257C_____9>`__.

**Note:** For information about limitations, see `Arcserve Cloud Cyber
Resilient Data Store
Related <cloud_cyber_resilient_data_store_related_lim.htm#cloud_data_store_related_lim.htm>`__.

Enhancements
------------
