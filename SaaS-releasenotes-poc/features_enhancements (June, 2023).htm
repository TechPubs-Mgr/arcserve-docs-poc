New Features and Enhancements (June, 2023)

This release includes the following new features and enhancements:

  • Single Sign-On (SSO): Arcserve supports Single Sign-On (SSO) to authenticate users through Okta (SAML) as an identity provider for Arcserve Console - SaaS. Single Sign-On (SSO) is an authentication method that allows you to access multiple applications with a single set of login credentials (for example, username and password). When you use SSO, you do not need to sign into every browser or an application during the same session.
  • Theme for User Interface: Allows you to set the color theme for the Arcserve Console - SaaS user interface. The available theme options include System Default, Light, and Dark modes. For more information, see Profile.
  • Integration of Hamburger Menu: The hamburger menu in Arcserve Console - SaaS allows you to do the following:
    • Access applications such as Arcserve UDP and Arcserve Cloud Direct.
    • Log out
  • Universal Logout: This option allows you to log out of the Okta session, all applications, and all the tabs or windows of the same browser session with a single action.
  • Assured Recovery: Arcserve Console - SaaS allows you to perform an assured recovery job to verify accessibility, assure recovery of the data, and provide the data integrity check. The assured recovery task comprises a source, test settings, schedule, and advanced settings. You can also run an Assured Recovery job manually. For more information, see How to Perform an Assured Recovery Test.
