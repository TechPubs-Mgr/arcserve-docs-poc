Platform Support

Important! Arcserve no longer supports 32-bit for Windows.

Arcserve Console - SaaS supports the following platforms:

Windows

  • Windows Server IoT 2025
  • Windows Server 2025
  • Windows Server IoT 2022
  • Windows Server 2022
  • Windows Server 2019
  • Windows Server IoT 2019 for Storage
  • Windows Server 2016
  • Windows Server 2012, 2012 R2
  • Windows Server 2008 R2 SP1

Linux

  • Red Hat Enterprise Linux 10.0
  • Oracle Enterprise Linux 10.0 - RHCK and UEK kernels
  • Rocky Linux 10.0
  • AlmaLinux 10.0
  • Debian 13.0
  • SUSE 15 SP7

Note: When performing BMR for RHEL, Rocky Linux, Alma Linux, or Oracle Linux 10.0, you cannot use the inbuilt Alma 9 based LiveCD included with Arcserve UDP 10.3 Linux Backup Server due to its limitations. Instead, download and use the Alma 10–based LiveCD. To download, click here.

Platforms

  • Nutanix AOS 7.0, 7.3, 7.5
  • vSphere 9.0
