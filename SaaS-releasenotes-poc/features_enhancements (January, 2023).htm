New Features and Enhancements (January, 2023)

This release includes the following new features and enhancements:

  • Arcserve Identity for Authentication: Arcserve Cloud Direct has changed its current built-in authentication system to Arcserve Identity. This system uses multiple authentication systems with different multi-factor methods such as OKTA Verify, Biometric Authenticator, Google Authenticator, and SMS Authenticator. Additionally, Arcserve Identity allows connection of Cloud Direct with other Arcserve products, thereby providing Single-Sign-On (SSO).
  • MSP Sub-organization: The MSP sub-organization admins previously owned user management. From this release, an exclusive MSP user management profile will manage the sub-organizations.
