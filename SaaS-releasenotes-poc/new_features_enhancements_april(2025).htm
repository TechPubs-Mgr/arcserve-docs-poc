New Features and Enhancements (April, 2025)

This release primarily provides the following:

New Features

  • Copy Recovery Points: Allows you to copy your backup data(recovery Points) from a source data store to a destination data store. For more information, see Copy Recovery Points.
  • Nutanix Files Support: Arcserve Console - SaaS now provides a way of protecting Nutanix Files using the UNC/NFS option. Nutanix Files is a software-defined, scale-out file storage solution that provides a repository for unstructured data, such as home directories, user profiles, departmental shares, application logs, backups, and archives. For more information, see Add a UNC or NFS Path.
  • Support for Arcserve Cloud Storage: Allows you to back up and replicate data to Arcserve-supported cloud storage. For more information, see Add a Cloud Account for Arcserve Cloud Storage.
  • Arcserve Cloud Cyber Resilient Data Store: Allows you to take immutable snapshots of an entire data store for enhanced protection against ransomware and other threats. For more information, see Add Arcserve Cloud Cyber Resilient Data Store.
  • Note: For information about limitations, see Arcserve Cloud Cyber Resilient Data Store Related.

    • Enhancements

    • Fixes and Security Updates: For more information, see the Issues Fixed list.
    • Overlay Text for Icons and Links: To improve the user experience, labels have been added as overlay text to help identify icons and links.
