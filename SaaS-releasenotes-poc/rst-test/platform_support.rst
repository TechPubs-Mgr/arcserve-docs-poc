Platform Support
================

**Important!** Arcserve no longer supports 32-bit for Windows.

Arcserve Console - SaaS supports the following platforms:

Windows
-------

- Windows Server IoT 2025
- Windows Server 2025
- Windows Server IoT 2022
- Windows Server 2022
- Windows Server 2019
- Windows Server IoT 2019 for Storage
- Windows Server 2016
- Windows Server 2012, 2012 R2
- Windows Server 2008 R2 SP1

Linux
-----

- Red Hat Enterprise Linux 10.0
- Oracle Enterprise Linux 10.0 - RHCK and UEK kernels
- Rocky Linux 10.0
- AlmaLinux 10.0
- Debian 13.0
- SUSE 15 SP7
