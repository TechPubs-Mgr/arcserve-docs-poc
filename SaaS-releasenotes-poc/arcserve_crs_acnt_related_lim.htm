Arcserve Cyber Resilient Storage Account Related

  • You cannot change the Cyber Resilient Storage IP/Host Name while modifying the Cyber Resilient Storage account. Arcserve recommends using a static IP for Cyber Resilient Storage server.
  • You cannot create an Arcserve Cyber Resilient Storage account in a remote or secondary site that shares the same name as an existing account in the local (primary) site. As a workaround, use a different name for the Arcserve Cyber Resilient Storage account in the remote or secondary site.
