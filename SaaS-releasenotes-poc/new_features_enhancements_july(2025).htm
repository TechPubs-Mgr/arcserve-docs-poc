New Features and Enhancements (July, 2025)

This release primarily provides the following:

New Features

  • Arcserve Cyber Resilient Storage Account Support: Allows you to back up and replicate data to Arcserve-supported cyber resilient storage. For more information, see Add an Arcserve Cyber Resilient Storage Account.
    • Arcserve Cyber Resilient Data Store: Allows you to take immutable snapshots of an entire data store to an on-premises storage endpoint for enhanced protection against ransomware and other threats. For more information, see Add an Arcserve Cyber Resilient Data Store.
    • Note: The Arcserve Cyber Resilient Storage feature requires a minimum Recovery Point Server (RPS) version of 10.2.
  • Request Trial: Allows you to request a trial for the following features using the Try It option.
    • Add Arcserve Cyber Resilient Data Store
    • Add Arcserve Cloud Data Store
    • Add Arcserve Cloud Cyber Resilient Data Store
