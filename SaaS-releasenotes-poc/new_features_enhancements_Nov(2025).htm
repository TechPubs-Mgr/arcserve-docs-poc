New Features and Enhancements (November, 2025)

This release primarily provides the following:

New Features

  • Assured Security - AI Anomaly Detection: This feature uses artificial intelligence to analyze data and identify records that deviate from normal behavior patterns. It examines backup recovery points and detects unusual activities, such as file system changes that may signal ransomware activity. The ransomware activity may include suspicious file names, encryption patterns, mass deletions, renames, and so on. For more information, see Add an Assured Security - AI Anomaly Detection Task to a Policy.
  • Arcserve Cyber Resilient Storage: Arcserve Cyber Resilient Storage now supports the following features:
    • Data Store Migration Support: You can migrate data stores from OneXafe storage to Arcserve Cyber Resilient Storage. This helps you move data easily and manage storage more efficiently.
    • Jumbo Frames Support: Arcserve Cyber Resilient Storage supports Jumbo Frames to improve network performance during large data transfers. Larger Ethernet frames reduce protocol overhead and the number of packets, which lowers CPU usage, reduces network congestion, and increases throughput. These improvements make replication, backup, and recovery faster and more reliable. They also strengthen cyber resilience by improving synchronization and reducing delay during data validation and integrity checks.
    • Extended RAID Parity Support: Arcserve Cyber Resilient Storage supports multiple parities in RAIDZ for better data protection and fault tolerance. Administrators can now define double or triple parity options for their pools to ensure higher reliability than in RAIDZ1. This works well for large storage pools or critical environments where drive failures are more likely.
    • Hot Spare Disk Support: Arcserve Cyber Resilient Storage supports hot spare disks. When a drive fails, the system automatically rebuilds data on the designated hot spare without manual action or downtime. This feature increases system reliability, prevents data loss, and reduces maintenance effort.
  • License Enforcement: The License Enforcement feature ensures compliance with capacity-based entitlements for Arcserve Cloud Storage (ACS) and Arcserve Cloud Cyber Resilient Storage (ACCRS). This mechanism is designed to monitor and regulate product usage, based on two independent metrics: storage capacity and license validity. You must renew or expand your license when the capacity or time limit is reached.
    • Storage Capacity: If the storage capacity is fully used, you must purchase additional capacity even when the license is active.
    • License Validity (Time Limit): If the license expires, you must renew the license.
  • When the license limit is exceeded, the system restricts actions such as creating new backups, using key features, or accessing cloud resources until you restore compliance. This helps maintain proper license usage and prevents unauthorized or excessive use of licensed resources. For more information, see Subscription and Storage Expiry Behavior in Arcserve Console - SaaS.

Enhancements

  • Assured Security - Malware Scan: Assured Security Scan has been renamed as Assured Security - Malware Scan.
  • Additional NIC Support for Arcserve Cyber Resilient Storage: Arcserve Cyber Resilient Storage now supports additional network interface cards (NICs), providing more flexibility for network and hardware configurations.
  • Assured Security Enhancements
    • Incremental Scan Support: Arcserve Console - SaaS now performs Assured Security Incremental Scans. Instead of rescanning the entire recovery point, it scans only new or changed files since the last scan. The system applies backend criteria to detect added, copied, or modified files and records the results accurately in the activity log. Activity log clearly shows whether each scan job ran a Full or an Incremental Scan.
    • ReFS Support: Assured Security now scans ReFS file systems in addition to NTFS. It supports ReFS versions 3.1, 3.4, 3.7, and 3.14 for both Full and Incremental Scans.
  • Notes:
    • Current scans cannot detect renamed or moved files because their creation or modification timestamps do not change. This enhancement is planned for the future.
    • Each scan job generates an antivirus scan result in the activity log.
