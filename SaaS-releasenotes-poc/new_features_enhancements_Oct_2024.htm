New Features and Enhancements (October, 2024)

The following new features and enhancements are available for Arcserve Console - SaaS:

  • Assured Security: Enables you to scan backup data in recovery points for any malware or malicious files. It also warns you about the malicious files in recovery points before restoring. For more information, see How to Perform an Assured Security Scan.
  • Notes:
    • The Assured Security scan is supported only for Windows nodes.
    • Applicable for Full, Incremental, Verify, and incomplete backup types of all the job types from custom, daily, weekly, and monthly schedule types.
  • Virtual Standby to Google Cloud Platform: Converts recovery points to virtual machine format on Google Cloud and prepares a snapshot to easily recover data when needed. This feature also provides the high availability capability and ensures that the virtual machine can take over immediately when the source machine fails. For more information, see How to Create a Virtual Standby to Google Cloud Policy.
  • Ad-hoc Standby VM: Converts recovery points to virtual machine format and prepares a snapshot to easily recover data when needed. This feature also provides the high availability capability and ensures that the virtual machine can take over immediately when the source machine fails. For more information, see How to Create an Ad-hoc Standby Virtual Machine.
  • Oracle RMAN Support: Arcserve Console - SaaS now provides a way of protecting Oracle system using Recovery Manager (RMAN). RMAN is an Oracle utility that performs backup, restore and recovery tasks on databases and automates the administration of backup strategies. For more information, see Add a Policy for Oracle Database Backup using Recovery Manager (RMAN).
  • Nutanix AHV VMs Protection: Enables adoption of Arcserve Console - SaaS for users requiring protection of Nutanix AHV VMs.
  • Audit Log: Provides an audit log of administrative events, including log-in events and changes (when/who/what), and restores that can serve the audit purposes. Ensures compliance to Client's (existing and potential) security requirement of Audit trails. Arcserve Console - SaaS allows you to export all audit records or selected audit records to a text file. For more information, see Analyze Audit Logs.
  • Mount SQL Database: Allows mounting of SQL databases to a particular Point in Time (PIT) between the n and n+1 recovery points. For more information, see How to Mount SQL Databases.
  • Import or Mount an Existing Data Store as a Read-Only Data Store: Allows you import or mount an existing data store as a read-only data store for recovery. It does not support the backup, merge, and purge jobs. For more information, see Import a Local Data Store and Import a Cloud Data Store.
  • One-to-Many Copy Support: Arcserve Console - SaaS now supports copying data from a single source to multiple data store destinations by allowing you to select a source data store from a Backup destination or from a Copy destination to be specified as source in the Copy To Another Data Store task. Additionally, it allows you to select if the next copy job starts only after the previous one is completed, or if they must start in parallel.
  • Note: This feature is applicable to Primary task and the Copy To Another Data Store task.
  • Azure Blob Storage Support for Deduplication: Allows you to create a dedupe data store on Azure Blob Storage. Azure Blob Storage is a massively scalable storage service for unstructured data. In Azure Storage, subscription-based storage accounts allow creation and management of Blob storage. It stores any type of text or binary data, such as a document file, media, or an application installer. For more information, see Add a Cloud Account.
  • Automatic New Linux Kernel Support: Enables support for the automatic update of kernels released on a regular basis for the RHEL/Alma/Rocky/OREL, Debian, and SUSE Linux versions resulting into the drivers with the outdated release. Additionally, it eliminates the need to manual compilation and shipment of a new driver package by CFT for each new kernel.
  • BMR Support for the RHEL, Alma, Rocky, and OREL 9.X Versions using Alma 9 LiveCD: Enables BMR support for the latest RHEL, Alma, Rocky, and OREL 9.X versions using Alma 9 LiveCD as older Centos LiveCD is not compatible. The new LiveCD is compatible with all the Linux older versions.
  • Increase of UNC Path Password Length: Allows you to use passwords having maximum of 120 characters for the RPS datastore destination UNC path.
  • TLS 1.3 Support: Enables support for TLS 1.3 to ensure data cannot be intercepted while transmitting over the internet.

Enhancements:

  • As part of a security enhancement, we have removed the need for a shared folder to access metadata files (such as index and reference files) stored in the datastore. Instead, metadata operations are now performed over a socket during backup, restore, copy, and other processes.
