UDP Related

The following features are available only in Arcserve UDP Console and are unavailable in Arcserve Console - SaaS.

  • O365 Backup primary task under Policy (Japanese version only).
  • Secondary tasks:
    • Copy Recovery Points
    • Copy to Tape
    • File Archive
    • File Copy
  • First backup (Full Backup) option
  • Retain by Recovery Sets option
  • Truncate log option for Exchange Server
  • HP-RMC storage array type
  • Retrieval Configuration option for the Replicate from a remotely-managed RPS task
  • Use selected network for replicate traffic option for the Replicate task
  • Linux Agent-Based backup task features:
    • Source local option under the Destination tab
    • Run the command even when the snapshot fails option under the Advanced tab
  • For Nutanix, Linux supports only Assured Recovery- Instant Virtual Machine (AR-IVM).
