Console Related
===============

- Arcserve Console - SaaS has the following limitations with respect to
  a policy:

  - When no policy is associated with a source, Arcserve Console - SaaS
    does not display the *Create an Instant VM* and *Create a Standby
    VM* options in the Actions drop-down list on the Sources page.
  - When a policy is associated with a source, Arcserve Console - SaaS
    displays the *Create an Instant VM* and *Create a Standby VM*
    options but does not list all the Recovery Point Serves and data
    stores in step 1 while performing ad-hoc VSB and Instant Virtual
    Machine from the Sources page. It lists only the Recovery Point
    Server that is being used in the Policy.
