UDP Related
===========

The following features are available only in Arcserve UDP Console and
are unavailable in Arcserve Console - SaaS.

- O365 Backup primary task under Policy (Japanese version only).
- Secondary tasks:

  - Copy Recovery Points
  - Copy to Tape
  - File Archive
  - File Copy

- First backup (Full Backup) option
- |image1|
- Retain by Recovery Sets option
- |image2|
- Truncate log option for Exchange Server
- |image3|
- HP-RMC storage array type
- |image4|
- Retrieval Configuration option for the Replicate from a
  remotely-managed RPS task
- |image5|
- Use selected network for replicate traffic option for the Replicate
  task
- |image6|
- Linux Agent-Based backup task features:

  - Source local option under the Destination tab
  - |image7|
  - Run the command even when the snapshot fails option under the
    Advanced tab
  - |image8|

- For Nutanix, Linux supports only Assured Recovery- Instant Virtual
  Machine (AR-IVM).
