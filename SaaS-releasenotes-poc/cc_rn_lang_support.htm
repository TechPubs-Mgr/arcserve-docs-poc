Language Support

A translated (localized) product provides local language support for the product user interface, online help, and other documentation, along with locale-specific default settings for date, time, currency, and number formats.

In this release, the Product User Interface is translated/localized into the following languages:

  • French
  • German
  • Italian
  • Japanese
  • Portuguese
  • Spanish

Note: Online product documentation is available only in English for this release.
